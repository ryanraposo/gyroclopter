Checking Automation…

1 · Chromebook Wi-Fi IP

ChromeOS Settings → Network → Wi-Fi → your connected network → IP address.

2 · Forward port 8443

ChromeOS Settings → Developers → Linux development environment → Port forwarding.

Add 8443 / TCP, label it Gyroclopter, and turn it on.

3 · Launch Gyroclopter

Open Gyroclopter from the ChromeOS launcher. Its QR code updates to the saved Wi-Fi IP automatically.

When both status lights are ready, scan the Gyroclopter QR code with your phone.
