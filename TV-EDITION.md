# Gyroclopter TV Edition

The phone remains the motion controller. A TV receiver shows a pairing QR code, connection state and a control surface suited to ten-foot viewing. Each receiver needs a local test surface for motion, selection and reconnect before distribution.

## First device

Start with [Android TV / Google TV](https://github.com/ryanraposo/gyroclopter/issues/27). Use an app-local cursor and standard D-pad focus as the first acceptance target. Handle left press/release, right action and scrolling using the same message types as the desktop server. Document separately any extra permissions needed for controls outside the receiver.

The first physical device pass should cover QR pairing from an iPhone and an Android phone, axes and sensitivity, selection, drag, scroll, Back, Wi-Fi loss, resume and a changed network address. The TV remote must be able to return to pairing and stop the receiver.
